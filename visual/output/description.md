# Tournament

The tournament component at version 0.5.0 provides ae/tournament version 1.0.0 to an illustrative application consumer, which in turn supplies ae/chip-ledger version 1.0.0 and ae/level-schedule version 1.0.0 and ae/seating version 1.0.0. The 4 arrows each run from a named output to a required input of the same type and version. Setting values shown are placeholders and secrets appear only as references.
